# Установка расширения «Watch a movie»

## Установка в Google Chrome / Chromium

1. Откройте страницу расширений: `chrome://extensions/`
2. Включите «Режим разработчика» (переключатель в правом верхнем углу).
3. Нажмите «Загрузить распакованное».
4. Выберите папку:
   `/browser_extension/Watch a movie`
5. Убедитесь, что расширение включено.

## Обновление после изменений

- На странице расширений нажмите кнопку перезагрузки у «Watch a movie» или
  кнопку «Обновить» для всех расширений.

# Как пользоваться

1. Откройте страницу на Кинопоиске:
2. Нажмите на иконку расширения, в попапе будет активна кнопка:
   - «Смотреть кино» для фильмов
   - «Смотреть сериал» для сериалов
3. Нажмите кнопку.

Если адрес не содержит ни `kinopoisk.ru/film`, ни `kinopoisk.ru/series/`,
кнопка будет отключена.

## Требуемые разрешения

- tabs, activeTab
- Доступ к хостам: `*://kinopoisk.ru/*`, `*://www.kinopoisk.ru/*`
