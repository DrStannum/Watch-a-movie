# Установка расширения «Watch a movie»

## Установка в Google Chrome / Chromium

1. Откройте страницу расширений: `chrome://extensions/`
2. Включите «Режим разработчика» (переключатель в правом верхнем углу)
3. Нажмите «Загрузить распакованное»
4. Выберите папку с расширением `Watch a movie`
5. Убедитесь, что расширение включено

## Обновление после изменений

На странице расширений нажмите кнопку перезагрузки у «Watch a movie».

## Как пользоваться

1. Откройте страницу фильма или сериала на Кинопоиске
2. Рядом с кнопкой «Буду смотреть» появится синяя кнопка:
   - **Смотреть кино** — на страницах фильмов
   - **Смотреть сериал** — на страницах сериалов
3. Нажмите на кнопку для перехода к просмотру

Также можно использовать popup расширения (клик по иконке в панели браузера).

## Требуемые разрешения

- `tabs`, `activeTab`
- Доступ к хостам: `kinopoisk.ru`, `www.kinopoisk.ru`, `hd.kinopoisk.ru`
